How to Run IntelliAssist AI Manually (Step-by-Step)
If you ever restart your system or want to run both services in separate terminal windows:

Step 1: Start the Backend (Terminal 1)
Open a PowerShell terminal and run:

powershell
cd "d:\IntelliAssist AI\backend"
.\.venv\Scripts\Activate.ps1
python server.py

Note: The FastAPI backend server will start on http://0.0.0.0:8000. It loads your Gemini API key from backend/.env, initializes the FAISS vector index, and connects to SQLite chat history.

Step 2: Start the Streamlit Frontend (Terminal 2)
Open a second PowerShell terminal and run:

powershell
cd "d:\IntelliAssist AI\backend"
.\.venv\Scripts\Activate.ps1
python run_streamlit.py

Note: The Streamlit UI will open at http://localhost:8501 and automatically connect to http://127.0.0.1:8000.

Step 3: If Port 8000 or 8501 Is Busy
If you need to free the ports to run the commands:

powershell
# Stop any processes using port 8501 (Streamlit Frontend)
Get-Process -Id (Get-NetTCPConnection -LocalPort 8501).OwningProcess -ErrorAction SilentlyContinue | Stop-Process -Force

# Stop any processes using port 8000 (FastAPI Backend)
Get-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess -ErrorAction SilentlyContinue | Stop-Process -Force

Then re-run python server.py and python run_streamlit.py.
